# 🦞 Lobster AI - Quick Start Guide

## What is Lobster AI?

A private, always-on AI assistant that:
- ✅ Runs completely on your device (100% local)
- ✅ Works on Telegram, Discord, Slack, and WhatsApp
- ✅ Has a quirky, helpful personality
- ✅ Never sends your data to the cloud
- ✅ Is fast and responsive

## Installation (3 Simple Steps)

### 1. Prerequisites
- Node.js 18+
- Local LLM (Ollama or LM Studio)

### 2. Install
```bash
git clone https://github.com/fadjar1233/personal-ai-assistant.git
cd personal-ai-assistant
npm install
```

### 3. Setup & Run
```bash
npm run setup  # Interactive configuration
npm start      # Start Lobster AI
```

That's it! 🎉

## First-Time Setup

The setup wizard will ask:

1. **Which LLM?** → Ollama or LM Studio
2. **Which chat apps?** → Telegram, Discord, Slack, WhatsApp (or all!)
3. **Platform tokens** → Paste bot tokens for each platform
4. **Personality** → Name and personality settings

## Start Using

Once running, you can:

### Telegram
- Search for your bot username
- Send any message
- Use commands: `/help`, `/clear`, `/info`

### Discord
- DM the bot
- Mention it in servers: `@Lobster hello`
- Works in threads too

### Slack
- DM the bot
- Mention it: `@Lobster what's up`

### WhatsApp
- Message like a normal contact
- Scan QR code when bot starts

## Troubleshooting

### "Can't connect to LLM"
```bash
# Make sure Ollama is running
ollama serve
# In another terminal, run Lobster
npm start
```

### "Bot not responding"
- Check `.env` has correct tokens
- Verify LLM is running
- Check logs: `npm run dev`

### "What models can I use?"
- Ollama: `mistral`, `neural-chat`, `llama2`, etc.
- LM Studio: Download models from their app
- Check [Ollama Library](https://ollama.ai/library)
